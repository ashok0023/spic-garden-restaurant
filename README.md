# Spice Garden — Premium Demo

Premium restaurant website demo for sales presentations.

## Demo-only content
Replace the phone number, address, menu prices, reviews, photos and business claims before delivering to a real client.

## Deploy
Upload `index.html`, `style.css`, `script.js` to Cloudflare Pages Direct Upload or another static host.
`index.html` must remain at the site root.

## Local test
python3 -m http.server 8000
Open http://localhost:8000

## Sales positioning
Suggested package: ₹5,000+ for the premium version, with domain, real business content, menu updates and WhatsApp/booking integration priced according to scope.
